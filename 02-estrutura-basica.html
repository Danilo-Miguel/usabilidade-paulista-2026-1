A estrutura fundamental de um documento HTML

Todo documento HTML válido segue uma estrutura específica. Esta estrutura garante que o navegador interprete corretamente o documento.

Código comentado - Documento HTML completo:

<!DOCTYPE html>


<html lang="pt-BR">


<head>

  <meta charset="UTF-8">


  <meta name="viewport" content="width=device-width, initial-scale=1.0">


  <title>Minha Primeira Página</title>

</head>

<body>

  <h1>Bem-vindo!</h1>
  <p>Este é um parágrafo.</p>
</body>

</html>

Elementos principais e sua história

1. <!DOCTYPE html>

Historicamente: Antes do HTML5, DOCTYPE era complexo e variado. Cada versão tinha uma declaração diferente (SGML, XHTML, etc).

HTML5 (2014): Simplificou enormemente: agora é apenas <!DOCTYPE html>

Por que existe: Informa ao navegador qual versão de HTML está sendo usada.

2. <html>

Criada em: HTML 1.0 (1991)

Propósito: Elemento raiz que envolve todo o documento.

Atributo lang: Especifica o idioma do documento (acessibilidade e SEO).

3. <head>

Criada em: HTML 1.0 (1991)

Propósito: Contém metadados sobre o documento. Nada aqui é exibido no corpo da página (exceto <title>).

Conteúdo típico:

  • <meta> - Metadados do documento
  • <title> - Título da página
  • <link> - Vinculação com arquivos externos (CSS)
  • <style> - Estilos CSS
  • <script> - Scripts JavaScript

4. <meta charset="UTF-8">

Criada em: HTML 2.0 (1995)

Por que foi criada: Diferentes idiomas usam diferentes conjuntos de caracteres. UTF-8 é o padrão moderno que suporta todos os alfabetos do mundo.

Importante: Sempre coloque isto como o primeiro <meta> do <head>

5. <meta name="viewport">

Criada em: 2010 (durante a era móvel)

Por que foi criada: Com o aumento de dispositivos móveis, era necessário informar ao navegador como lidar com diferentes tamanhos de tela.

O que faz:

  • width=device-width - Usa a largura real do dispositivo
  • initial-scale=1.0 - Define zoom inicial em 100%

6. <title>

Criada em: HTML 1.0 (1991)

Propósito: Define o título da página que aparece na aba do navegador, nos marcadores e nos resultados de busca.

Importante para: SEO, experiência do usuário e acessibilidade.

7. <body>

Criada em: HTML 1.0 (1991)

Propósito: Contém todo o conteúdo visível da página ao usuário. Tudo que o visitante vê está dentro do <body>.

Elementos blocos vs. inline

Blocos (ocupam linha inteira)

  • <div> - Divisão genérica
  • <p> - Parágrafo
  • <h1> a <h6> - Títulos
  • <header>, <footer>, <section> - Semânticos

Inline (fluem dentro do texto)

  • <span> - Contêiner genérico inline
  • <a> - Links
  • <strong>, <em>, <b>, <i> - Formatação
  • <img> - Imagens

Checklist de estrutura básica

Use este checklist para verificar se seu documento HTML é válido:

  • ☑ Começa com <!DOCTYPE html>
  • ☑ Tem abertura <html> e fechamento </html>
  • ☑ Dentro de <html> tem <head> e <body>
  • ☑ <head> contém <meta charset="UTF-8">
  • ☑ <head> contém <title>
  • ☑ <head> contém <meta viewport> para mobile
  • ☑ Todo conteúdo visível está em <body>
