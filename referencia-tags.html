Introdução

Esta é uma referência rápida de todas as tags HTML importantes, com explicações semânticas, históricas e exemplos de uso.

Nota: Use Ctrl+F para buscar uma tag específica

Estrutura Básica do Documento

<!DOCTYPE html>

Criada: HTML 1.0 (1991)

Semântica: Declara a versão e tipo do documento

História: Originalmente era complexo (SGML), simplificado em HTML5

Exemplo: <!DOCTYPE html> (sempre na primeira linha)

<html>

Criada: HTML 1.0 (1991)

Semântica: Elemento raiz que encapsula todo o documento

Atributo importante: lang="pt-BR" (especifica idioma)

Exemplo: <html lang="pt-BR">...</html>

<head>

Criada: HTML 1.0 (1991)

Semântica: Contém metadados sobre o documento

Conteúdo típico: title, meta, link, style, script

Importante: Nada aqui aparecer na página (exceto title)

<body>

Criada: HTML 1.0 (1991)

Semântica: Contém todo o conteúdo visível da página

Exemplo: <body>Aqui entra tudo que vemos</body>

<meta>

Criada: HTML 2.0 (1995)

Semântica: Define metadados (informações sobre a página)

Exemplos principais:

  • <meta charset="UTF-8"> - Conjunto de caracteres
  • <meta name="viewport" content="width=device-width"> - Responsividade
  • <meta name="description" content="..."> - Descrição para busca

<title>

Criada: HTML 1.0 (1991)

Semântica: Define o título da página (aparece na aba)

Importância: Muito importante para SEO

Exemplo: <title>Minha Página HTML</title>

<link>

Criada: HTML 2.0 (1995)

Semântica: Vincula recursos externos (CSS, fonts, etc)

Exemplo mais comum: <link rel="stylesheet" href="style.css">

<style>

Criada: HTML 3.2 (1997)

Semântica: Define estilos CSS no documento

Exemplo: <style> h1 { color: blue; } </style>

<script>

Criada: HTML 3.2 (1997)

Semântica: Define ou importa código JavaScript

Exemplo: <script src="app.js"></script>

Textos e Formatação

<h1> a <h6>

Criadas: HTML 1.0 (1991)

Semântica: Definem títulos com hierarquia (h1 = principal, h6 = menor)

Importância: Essencial para estrutura e SEO. Use apenas um <h1> por página

Exemplo: <h1>Título Principal</h1>, <h2>Subtítulo</h2>

<p>

Criada: HTML 1.0 (1991)

Semântica: Define um parágrafo de texto

Características: Browser adiciona espaço antes e depois automaticamente

Exemplo: <p>Este é um parágrafo de texto.</p>

<strong>

Criada: HTML 2.0 (1995)

Semântica: Marca texto muito importante (importância semântica)

Visualização: Negrito (bold)

Exemplo: <strong>Muito importante</strong>

<em>

Criada: HTML 1.0 (1991)

Semântica: Marca texto que deve ser enfatizado

Visualização: Itálico (italic)

Diferença de <i>: <em> é semântico (significado), <i> é apenas visual

Exemplo: <em>Esta palavra é enfatizada</em>

<b>

Criada: HTML 1.0 (1991)

Semântica: Apenas formatação visual (SEM significado semântico)

Visualização: Negrito

Recomendação: Prefira <strong> para dados importantes

<i>

Criada: HTML 1.0 (1991)

Semântica: Apenas formatação visual (SEM significado semântico)

Visualização: Itálico

Recomendação: Prefira <em> para ênfase real

<mark>

Criada: HTML5 (2014)

Semântica: Marca texto como destacado/relevante

Visualização: Fundo amarelo (marca-texto)

Exemplo: Encontrei a palavra <mark>importante</mark>

<code>

Criada: HTML 2.0 (1995)

Semântica: Marca código de computador inline

Exemplo: Use <code>var x = 5;</code> em JavaScript

<pre>

Criada: HTML 2.0 (1995)

Semântica: Texto pré-formatado (preserva espaçamento e quebras)

Uso: Código, poesia, ASCII art

Exemplo: <pre> espaçamento é preservado </pre>

<br>

Criada: HTML 2.0 (1995)

Semântica: Quebra de linha

Tipo: Tag vazia (sem conteúdo)

Nota: Não use para espaçamento (use CSS para isso)

<hr>

Criada: HTML 2.0 (1995)

Semântica: Linha horizontal (divisão de tópicos)

Tipo: Tag vazia

<small>

Criada: HTML 3.2 (1997)

Semântica: Marca comentários secundários/informação pequena

Exemplo: <small>Nota: Esta informação é complementar</small>

<del>

Criada: HTML 4.0 (1997)

Semântica: Marca texto deletado

Visualização: Tachado (strikethrough)

Exemplo: Preço original <del>R$ 100</del> agora R$ 50

<ins>

Criada: HTML 4.0 (1997)

Semântica: Marca texto inserido/novo

Visualização: Sublinhado

Exemplo: Ele é <ins>muito talentoso</ins>

<sub> e <sup>

Criadas: HTML 3.2 (1997)

Semântica: Subscrito e sobrescrito

Exemplo: H<sub>2</sub>O e E=mc<sup>2</sup>

Listas

<ul>

Criada: HTML 1.0 (1991)

Semântica: Lista desordenada (sem ordem específica)

Marcador: • (bullet points)

Exemplo: <ul><li>Item 1</li></ul>

<ol>

Criada: HTML 1.0 (1991)

Semântica: Lista ordenada (sequência específica)

Marcador: 1, 2, 3, ... (numeração)

Exemplo: <ol type="1"><li>Primeiro</li></ol>

<li>

Criada: HTML 1.0 (1991)

Semântica: Item de lista (filho de <ul>, <ol> ou <dl>)

Exemplo: <li>Este é um item</li>

<dl>, <dt>, <dd>

Criadas: HTML 2.0 (1995)

Semântica: Lista de definição (termos com definições)

Uso: Glossários, FAQs, metadados

Exemplo:

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
</dl>

Links e Navegação

<a>

Criada: HTML 1.0 (1991)

Semântica: Cria um hyperlink ou âncora

História: Elemento MAIS IMPORTANTE da web - conecta documentos

Atributos:

  • href - Destino do link (URL ou ID)
  • target - Como abrir ("_blank" = nova aba)
  • title - Dica ao passar mouse

Exemplo: <a href="pagina.html">Clique aqui</a>

<nav>

Criada: HTML5 (2014)

Semântica: Marca seção de navegação principal

Importância: Essencial para acessibilidade

Exemplo: Ver Lição 5

Imagens e Multimídia

<img>

Criada: HTML 2.0 (1995)

Semântica: Insere uma imagem na página

Tipo: Tag vazia (sem conteúdo)

Atributos obrigatórios:

  • src - Caminho da imagem
  • alt - Texto alternativo (MUITO importante!)

Exemplo: <img src="foto.jpg" alt="Descrição da foto">

<figure> e <figcaption>

Criadas: HTML5 (2014)

Semântica: Agrupa imagem com sua legenda

Exemplo: Ver Lição 6

<video>

Criada: HTML5 (2014)

Semântica: Reproduz vídeo nativamente (sem Flash)

Atributos: controls, autoplay, loop, width, height

Revolucionou: A forma como servemos vídeos na web

<audio>

Criada: HTML5 (2014)

Semântica: Reproduz áudio nativamente

Atributos: controls, autoplay, loop

<source>

Criada: HTML5 (2014)

Semântica: Define múltiplas fontes para <video> ou <audio>

Propósito: Compatibilidade com diferentes navegadores e formatos

<canvas>

Criada: HTML5 (2014)

Semântica: Área para desenho com JavaScript

Uso: Gráficos, animações, jogos

<svg>

Criada: 2011 (integrado em HTML5)

Semântica: Gráficos vetoriais escaláveis

Vantagem: Infinitamente escalável sem perda de qualidade

Formulários

<form>

Criada: HTML 2.0 (1995)

Semântica: Container que agrupa campos de entrada

Atributos importantes:

  • action - URL para enviar dados
  • method - GET ou POST

<input>

Criada: HTML 2.0 (1995)

Semântica: Campo de entrada de dados

Tipo: Tag vazia

Tipos principais: text, email, password, number, date, checkbox, radio, submit

<textarea>

Criada: HTML 2.0 (1995)

Semântica: Campo de texto multilinha

Exemplo: <textarea rows="5" cols="40"></textarea>

<label>

Criada: HTML 4.0 (1997)

Semântica: Associa texto com campo de entrada

Importância: Essencial para acessibilidade e usabilidade

Exemplo: <label for="email">Email:</label><input id="email">

<select> e <option>

Criadas: HTML 2.0 (1995)

Semântica: Lista suspensa para seleção

Exemplo: Ver Lição 7

<fieldset> e <legend>

Criadas: HTML 4.0 (1997)

Semântica: Agrupa campos relacionados com título

Importância: Melhora organização e acessibilidade

<button>

Criada: HTML 4.0 (1997)

Semântica: Botão clicável com funcionalidade customizável

Exemplo: <button type="submit">Enviar</button>

Tabelas

<table>

Criada: HTML 3.2 (1997)

Semântica: Container para dados tabulares

Importante: NUNCA use para layout (use CSS)

<tr>

Significa: Table Row

Semântica: Define uma linha da tabela

<td>

Significa: Table Data

Semântica: Define uma célula de dados

<th>

Significa: Table Header

Semântica: Define uma célula de cabeçalho (MAIS IMPORTANTE que <td>)

<thead>, <tbody>, <tfoot>

Criadas: HTML 4.0 (1997)

Semântica: Agrupa seções semanticamente (cabeçalho, corpo, rodapé)

Importância: Essencial para acessibilidade e estrutura

<caption>

Criada: HTML 3.2 (1997)

Semântica: Título/descrição da tabela

Elementos Semânticos Estruturais (HTML5)

<header>

Criada: HTML5 (2014)

Semântica: Cabeçalho de página ou seção

<main>

Criada: HTML5 (2014)

Semântica: Conteúdo principal da página (único)

<section>

Criada: HTML5 (2014)

Semântica: Seção temática de conteúdo

<article>

Criada: HTML5 (2014)

Semântica: Conteúdo independente reutilizável

<aside>

Criada: HTML5 (2014)

Semântica: Conteúdo tangencial/barra lateral

<footer>

Criada: HTML5 (2014)

Semântica: Rodapé de página ou seção

Elementos Genéricos (sem semântica específica)

<div>

Criada: HTML 3.2 (1997)

Semântica: Divisão/container genérico (bloco)

Nota: Use quando não há elemento semântico apropriado

<span>

Criada: HTML 3.2 (1997)

Semântica: Contêiner genérico inline

Uso: Para estilizar texto ou wrap em contexto inline

Atributos Globais (Funcionam em qualquer tag)

  • id - Identificador único do elemento
  • class - Classificação para CSS
  • style - Estilos inline (evite usar)
  • title - Texto alternativo ao passar mouse
  • data-* - Dados customizados para JavaScript
  • hidden - Oculta o elemento
  • contenteditable - Permite edição pelo usuário
  • draggable - Permite arrastar
  • tabindex - Ordem de tabulação

Entidades HTML (Para caracteres especiais)

  • &lt; - < (menor que)
  • &gt; - > (maior que)
  • &amp; - & (e comercial)
  • &quot; - " (aspas)
  • &nbsp; - Espaço não-quebrável
  • &copy; - © (copyright)
  • &reg; - ® (registrado)
