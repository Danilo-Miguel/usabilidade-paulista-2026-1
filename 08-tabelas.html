Tabelas HTML

Criadas em: HTML 3.2 (1997)

Propósito: Exibir dados estruturados em linhas e colunas.

Histórico importante: No passado, tabelas eram usadas incorretamente para layout. Hoje, CSS handle layout e tabelas devem ser usadas apenas para dados tabulares.

Estrutura básica de uma tabela

Elementos principais:

<table>

Propósito: Container da tabela inteira

<tr>

Significa: Table Row (linha de tabela)

Propósito: Define uma linha

<td>

Significa: Table Data (dado de tabela)

Propósito: Define uma célula de dados

<th>

Significa: Table Header (cabeçalho de tabela)

Propósito: Define uma célula de cabeçalho (importante para semântica!)

Exemplo simples com comentários

<!-- Tabela simple com 2 linhas e 3 colunas -->
<table border="1">
  <!-- Primeira linha é cabeçalho -->
  <tr>
    <th>Nome</th>
    <th>Idade</th>
    <th>Cidade</th>
  </tr>
  <!-- Segunda linha com dados -->
  <tr>
    <td>João</td>
    <td>28</td>
    <td>São Paulo</td>
  </tr>
</table>

Resultado visual:

Nome Idade Cidade
João 28 São Paulo
Maria 25 Rio de Janeiro

Estrutura semântica completa

Para tabelas mais complexas, use <thead>, <tbody> e <tfoot>:

Código com comentários:

<table border="1">
  <!-- thead agrupa linhas de cabeçalho -->
  <thead>
    <tr>
      <th>Produto</th>
      <th>Preço</th>
      <th>Quantidade</th>
    </tr>
  </thead>
  
  <!-- tbody agrupa dados principais -->
  <tbody>
    <tr>
      <td>Laptop</td>
      <td>R$ 3000</td>
      <td>5</td>
    </tr>
    <tr>
      <td>Mouse</td>
      <td>R$ 50</td>
      <td>15</td>
    </tr>
  </tbody>
  
  <!-- tfoot agrupa totais ou resumos -->
  <tfoot>
    <tr>
      <th>Total</th>
      <th>R$ 3050</th>
      <th>20</th>
    </tr>
  </tfoot>
</table>

Resultado visual:

Produto Preço Quantidade
Laptop R$ 3000 5
Mouse R$ 50 15
Total R$ 3050 20

<thead>, <tbody> e <tfoot>

<thead>

Criada em: HTML 4.0 (1997)

Propósito: Agrupa semanticamente as linhas de cabeçalho

Benefícios:

  • Melhora semântica do documento
  • Leitores de tela identificam como cabeçalho
  • Permite CSS diferente para cabeçalho
  • Leitores de telas podem repetir cabeçalho ao rolar

<tbody>

Criada em: HTML 4.0 (1997)

Propósito: Agrupa o corpo principal da tabela

<tfoot>

Criada em: HTML 4.0 (1997)

Propósito: Agrupa linhas de resumo/total no final

Mesclagem de células

colspan (unir colunas)

<td colspan="2">Esta célula ocupa 2 colunas</td>

rowspan (unir linhas)

<td rowspan="3">Esta célula ocupa 3 linhas</td>

Exemplo visual:

Cabeçalho mesclado Coluna 3
Célula 1 Célula 2 Mesclado
Célula 3 Célula 4

Atributos da tabela

border

<table border="1"> - Mostra bordas
<table border="0"> - Sem bordas

cellpadding

<table cellpadding="10"> - Espaço dentro das células

cellspacing

<table cellspacing="5"> - Espaço entre as células

summary

<table summary="Tabela de vendas por mês">

Propósito: Descrição para leitores de tela

caption

<table>
  <caption>Vendas de 2025</caption>
  ...
</table>

Propósito: Título visível da tabela

Exemplo completo: Tabela de horário

<table border="1">
  <caption><strong>Horário de Aulas - Turma A</strong></caption>
  
  <thead>
    <tr>
      <th>Horário</th>
      <th>Segunda</th>
      <th>Terça</th>
      <th>Quarta</th>
    </tr>
  </thead>
  
  <tbody>
    <tr>
      <td>08:00</td>
      <td>Português</td>
      <td>Matemática</td>
      <td>Inglês</td>
    </tr>
    <tr>
      <td>09:00</td>
      <td>História</td>
      <td>Ciência</td>
      <td>Educação Física</td>
    </tr>
  </tbody>
  
</table>

Boas práticas com tabelas

  • Use <table> apenas para dados tabulares
  • Nunca use tabelas para layout (use CSS Grid ou Flexbox)
  • Sempre use <thead>, <tbody>, <tfoot> apropriadamente
  • Use <th> para cabeçalhos, não <td>
  • Adicione <caption> para descrição da tabela
  • Use atributos scope em <th> para indicar direção (row/col)
  • Mantenha tabelas simples e compreensíveis
  • Considere responsividade em dispositivos móveis

O atributo scope (importante para acessibilidade)

Indica se o cabeçalho é para linha ou coluna:

<th scope="row">Janeiro</th>  <!-- Cabeçalho de linha -->
<th scope="col">Vendas</th>  <!-- Cabeçalho de coluna -->

Benefício: Leitores de tela entendem melhor a estrutura
