Três tipos de listas no HTML

HTML oferece três tipos de listas para organizar informações de forma estruturada.

1. Listas Desordenadas: <ul>

Criada em: HTML 1.0 (1991)

Propósito: Lista itens sem ordem específica. Cada item aparece com um marcador (bullet).

Código comentado:

<!-- Marca o início da lista desordenada -->
<ul>
  <!-- Cada <li> é um item da lista -->
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

Resultado visual:

  • Maçã
  • Banana
  • Laranja

Quando usar:

  • Receitas de ingredientes
  • Lista de compras
  • Características de um produto
  • Itens sem ordem específica

2. Listas Ordenadas: <ol>

Criada em: HTML 1.0 (1991)

Propósito: Lista itens em ordem específica. Cada item é numerado.

Código comentado:

<!-- Marca o início da lista ordenada -->
<ol>
  <!-- Numeração automática: 1, 2, 3... -->
  <li>Primeiro passo</li>
  <li>Segundo passo</li>
  <li>Terceiro passo</li>
</ol>

Resultado visual:

  1. Acordar
  2. Tomar café
  3. Ir para o trabalho

Variações de numeração:

<!-- type="a" usa letras minúsculas -->
<ol type="a">
  <li>Primeiro</li>
  <li>Segundo</li>
</ol>

Valores válidos para type:

  • "1" - Números (padrão): 1, 2, 3
  • "A" - Letras maiúsculas: A, B, C
  • "a" - Letras minúsculas: a, b, c
  • "I" - Algarismos romanos maiúsculos: I, II, III
  • "i" - Algarismos romanos minúsculos: i, ii, iii

Quando usar:

  • Instruções passo a passo
  • Rankings
  • Procedimentos
  • Itens em ordem importante

3. Listas de Definição: <dl>

Criada em: HTML 2.0 (1995)

Propósito: Associa termos com suas definições. Perfeito para glossários.

Código comentado:

<!-- dl = definition list (lista de definição) -->
<dl>
  <!-- dt = definition term (termo para definir) -->
  <dt>HTML</dt>
  <!-- dd = definition description (definição) -->
  <dd>HyperText Markup Language - linguagem de marcação da web</dd>
  
  <dt>CSS</dt>
  <dd>Cascading Style Sheets - linguagem de estilos</dd>
</dl>

Resultado visual:

SEO
Search Engine Optimization - otimização para mecanismos de busca
API
Application Programming Interface - interface de programação
URL
Uniform Resource Locator - endereço de uma página web

Quando usar:

  • Glossários
  • Definições de termos
  • Perguntas e respostas
  • Metadados estruturados

Listas aninhadas (listas dentro de listas)

Você pode colocar uma lista dentro de outra lista:

Código comentado:

<ol>
  <li>Frutas
    <ul>
      <li>Maçã</li>
      <li>Banana</li>
    </ul>
  </li>
  <li>Vegetais
    <ul>
      <li>Cenoura</li>
      <li>Brócolis</li>
    </ul>
  </li>
</ol>

Resultado visual:

  1. Frutas
    • Maçã
    • Banana
  2. Vegetais
    • Cenoura
    • Brócolis

Elemento <li> (List Item)

Criada em: HTML 1.0 (1991)

Propósito: Representa um item em qualquer tipo de lista.

Importante: <li> deve estar sempre dentro de <ul>, <ol> ou <dl>.

Boas práticas com listas

  • Use <ul> para itens sem ordem específica
  • Use <ol> para itens que seguem uma sequência
  • Use <dl> para termos e definições
  • Sempre aninha listas corretamente (não deixe <li> órfão)
  • Não use listas apenas para formatação visual
  • Mantenha a semântica - escolha o tipo certo de lista
  • Use listas aninhadas para estrutura hierárquica
