Elementos de texto e formatação

HTML oferece várias tags para estruturar e formatar texto. Cada uma tem um propósito semântico específico.

Parágrafos: <p>

Criada em: HTML 1.0 (1991)

Propósito: Representa um parágrafo de texto. O navegador automaticamente adiciona espaço antes e depois de cada parágrafo.

Código comentado:

<p>Este é meu primeiro parágrafo.</p>
<p>Este é meu segundo parágrafo.</p>

Nota: Use <p> para parágrafos, não para espaçamento. (Para espaçamento, use CSS depois que aprender)

Títulos: <h1> a <h6>

Criadas em: HTML 1.0 (1991)

Propósito: Estruturam hierarquicamente o conteúdo da página.

Exemplo de hierarquia correta:

<h1>Título Principal (Site)</h1>
  <h2>Seção Principal</h2>
    <h3>Subseção</h3>
    <h3>Outra Subseção</h3>
  <h2>Outra Seção Principal</h2>

Regras importantes:

  • Use apenas um <h1> por página (o título principal)
  • Não pule níveis (não vá de <h1> diretamente para <h3>)
  • Use para estrutura, não apenas para tamanho de fonte
  • Muito importante para SEO (otimização em busca)
  • Essencial para acessibilidade (leitores de tela)

Formatação Semântica

<strong>

Criada em: HTML 2.0 (1995)

Propósito: Marca texto muito importante semanticamente.

<p>Este é um texto <strong>muito importante</strong></p>

Diferença: Semanticamente significa importância (leitores de tela enfatizam), visualmente aparece em negrito.

<em>

Criada em: HTML 1.0 (1991)

Propósito: Marca texto que deve ser enfatizado (ênfase).

<p>Você <em>deve</em> entender isto.</p>

Diferença: Semanticamente significa ênfase, visualmente aparece em itálico.

<b> (não recomendado)

Criada em: HTML 1.0 (1991)

Propósito: Apenas formatação visual (sem significado semântico).

Quando usar: Raramente. Prefira <strong> para texto que precisa destaque semântico.

<i> (não recomendado)

Criada em: HTML 1.0 (1991)

Propósito: Apenas formatação visual (sem significado semântico).

Quando usar: Raramente. Às vezes para nomes científicos ou citações.

Formatação Técnica

<code>

Criada em: HTML 2.0 (1995)

Propósito: Marca código de computador inline: var x = 5;

<p>Use <code>console.log()</code> em JavaScript</p>

<pre>

Criada em: HTML 2.0 (1995)

Propósito: Preserva espaçamento e quebras de linha (para código ou poesia).

<pre>
  function teste() {
    console.log("Alinhamento preservado!");
  }
</pre>

<mark>

Criada em: HTML5 (2014)

Propósito: Marca texto destacado (como um marca-texto amarelo).

<p>Encontrei a palavra <mark>importante</mark></p>

Quebras de linha e linhas horizontais

<br>

Criada em: HTML 2.0 (1995)

Propósito: Cria uma quebra de linha dentro de um parágrafo.

<p>Mary had a little lamb<br>
Its fleece was white as snow</p>

Importante: <br> é uma tag vazia (não tem conteúdo). Tag vazia pode ser escrita como <br> ou <br/>

<hr>

Criada em: HTML 2.0 (1995)

Propósito: Cria uma linha horizontal para separar seções.

<p>Fim da seção</p>
<hr>
<p>Início de nova seção</p>

Outros elementos importantes

<small>

Criada em: HTML 3.2 (1997)

Propósito: Marca comentários não essenciais ou informações secundárias.

Este texto é pequeno e complementar.

<del>

Criada em: HTML 4.0 (1997)

Propósito: Marca texto deletado.

<p>O preço era R$ 100 agora é R$ 50</p>

<ins>

Criada em: HTML 4.0 (1997)

Propósito: Marca texto inserido/adicionado.

<p>Ele é muito talentoso</p>

<sub> e <sup>

Criadas em: HTML 3.2 (1997)

Propósito: Subscrito (sub) e sobrescrito (sup).

<p>H2O = E=mc2</p>

Boas práticas

  • Use <strong> em vez de <b>
  • Use <em> em vez de <i>
  • Use hierarquia correta de títulos (<h1> a <h6>)
  • Estruture com <p>, não com <br>
  • Use <small> para informações complementares
  • Prefira semântica visual
