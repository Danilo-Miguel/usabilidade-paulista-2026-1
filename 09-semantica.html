O que é semântica em HTML?

Semântica significa usar o elemento HTML certo para o propósito certo, comunicando não apenas visualmente, mas também o significado do conteúdo.

Exemplo:

❌ <div style="font-size: 32px; font-weight: bold;">Título</div>

✅ <h1>Título</h1>

Ambos exibem um título grande e negrito, mas apenas <h1> comunica: "isto é um título principal".

Por que usar HTML semântico?

  • Acessibilidade: Leitores de tela entendem melhor
  • SEO: Motores de busca indexam melhor
  • Manutenibilidade: Código mais legível e manutenível
  • Compatibilidade: Melhor suporte em dispositivos antigos
  • Semântica: Comunica intenção do desenvolvimento
  • Validação: Código mais válido e correto

Elementos semânticos estruturais do HTML5

Introduzidos em: HTML5 (2014)

<header>

Propósito: Define o cabeçalho de uma página ou seção

<header>
  <h1>Meu Blog</h1>
  <p>Artigos sobre desenvolvimento web</p>
</header>

Quando usar: Topo da página ou de uma seção; geralmente contém título

<nav>

Propósito: Define seção de navegação principal

<nav>
  <ul>
    <li><a href="/">Início</a></li>
    <li><a href="/sobre">Sobre</a></li>
  </ul>
</nav>

Quando usar: Menu de navegação principal da página

<main>

Propósito: Define o conteúdo principal único da página

<main>
  <article>...</article>
</main>

Quando usar: Contém o conteúdo único sem repetição (apenas um por página)

<section>

Propósito: Define uma seção temática de conteúdo

<section>
  <h2>Capítulo 1: Introdução</h2>
  <p>Texto do capítulo...</p>
</section>

<section>
  <h2>Capítulo 2: Desenvolvimento</h2>
  <p>Mais texto...</p>
</section>

Quando usar: Agrupar conteúdo relacionado por tema mantendo hierarquia

<article>

Propósito: Define conteúdo independente e reutilizável

<article>
  <h1>Como aprender HTML</h1>
  <p>Por: João Silva</p>
  <p>Conteúdo do artigo...</p>
</article>

Quando usar: Blog posts, notícias, comentários - coisas que podem ser reutilizadas

<aside>

Propósito: Define conteúdo secundário (barra lateral, anúncios, etc)

<aside>
  <h3>Artigos Populares</h3>
  <ul>
    <li><a href="#">Artigo 1</a></li>
  </ul>
</aside>

Quando usar: Conteúdo tangencial, barras laterais, citações

<footer>

Propósito: Define o rodapé de uma página ou seção

<footer>
  <p>© 2026 Meu Blog. Todos direitos reservados.</p>
  <nav><a href="#">Privacidade</a></nav>
</footer>

Quando usar: No final da página ou seção; contém info de rodapé

Exemplo de layout semântico completo

<!DOCTYPE html>
<html>
<head>...</head>

<body>
  <!-- Cabeçalho do site -->
  <header>
    <h1>Meu Blog</h1>
  </header>
  
  <!-- Navegação principal -->
  <nav>
    <ul>
      <li><a href="/">Início</a></li>
      <li><a href="/sobre">Sobre</a></li>
    </ul>
  </nav>
  
  <!-- Conteúdo principal -->
  <main>
    <article>
      <h2>Meu Primeiro Artigo</h2>
      <p>Conteúdo...</p>
    </article>
  </main>
  
  <!-- Barra lateral -->
  <aside>
    <h3>Populares</h3>
  </aside>
  
  <!-- Rodapé -->
  <footer>
    <p>© 2026. Todos direitos.</p>
  </footer>
</body>
</html>

Elementos semânticos de conteúdo

<address>

Propósito: Define informações de contato

<address>
  Rua das Flores, 123
  São Paulo, SP
  email@example.com
</address>

<time>

Propósito: Marca data/hora do máquina-legível

<p>Publicado em <time datetime="2026-02-25">25 de fevereiro</time></p>

<blockquote>

Propósito: Marca uma citação em bloco

<blockquote>
  <p>A web é para todos</p>
  <footer>— Tim Berners-Lee</footer>
</blockquote>

<quote>

Propósito: Marca uma citação inline curta

<p>Como disse Tim, <q>a web é para todos</q>.</p>

Dicas de quando usar <section> vs <article>

Elemento Quando usar Exemplo
<section> Agrupar conteúdo relacionado por tema Capítulos de um livro
<article> Conteúdo independente e reutilizável Post de blog, notícia

Boas práticas seminânticas

  • Use elementos semânticos apropriados para cada tipo de conteúdo
  • Não use <div> quando há elemento semântico apropriado
  • Mantenha hierarquia correta de títulos (<h1> a <h6>)
  • Use <header>, <nav>, <main>, <footer> para estrutura de página
  • Use <section> para agrupar conteúdo temático
  • Use <article> para conteúdo independente
  • Use <aside> para conteúdo tangencial
  • Valide seu HTML em validator.w3.org
