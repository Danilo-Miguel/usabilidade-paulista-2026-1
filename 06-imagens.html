O elemento <img> - Imagens

Criada em: HTML 2.0 (1995)

Propósito: Insere uma imagem na página web.

Por que foi criada: HTML inicial era apenas texto. A adição de imagens tornou a web visualmente interessante e levou à expansão explosiva da web.

Sintaxe básica

<!-- img é uma tag vazia (sem conteúdo) -->
<img src="caminho/imagem.jpg" alt="Descrição">

Atributos essenciais:

src

O que faz: Especifica o caminho da imagem

Obrigatório: Sim

<img src="foto.jpg">  <!-- Arquivo local -->
<img src="imgs/foto.jpg">  <!-- Em subpasta -->
<img src="https://site.com/img.jpg">  <!-- URL externa -->

alt

Criada em: HTML 4.0 (1997)

O que faz: Texto alternativo que aparece quando imagem não carrega e é lido por leitores de tela

Obrigatório: Sim (por acessibilidade e semântica)

<img src="logo.png" alt="Logo da empresa XYZ">

Importância: Crucial para:

  • Acessibilidade (deficientes visuais)
  • SEO (ferramentas de busca lêem alt)
  • Confiabilidade (se imagem não carregar)

Atributos adicionais da tag <img>

width e height

O que fazem: Definem largura e altura da imagem

<img src="foto.jpg" alt="Foto" width="300" height="200">

Importante: Pode ser em pixels (300) ou percentual (50%)

title

O que faz: Texto que aparece ao passar o mouse

<img src="logo.png" alt="Logo" title="Logo da empresa">

loading

Criada em: HTML5 (2014)

O que faz: Define como carregar a imagem

<img src="imagem-grande.jpg" alt="Imagem" loading="lazy">

Valores:

  • "eager" - Carrega imediatamente (padrão)
  • "lazy" - Carrega apenas quando está próxima de ser vista (melhora performance)

Dentro de links

Você pode colocar uma imagem dentro de um link:

Código comentado:

<!-- Link com imagem -->
<a href="pagina.html">
  <img src="logo.png" alt="Ir para página inicial">
</a>

O elemento <figure> e <figcaption>

Criadas em: HTML5 (2014)

Propósito: Associam uma imagem com sua caption (legenda) semanticamente.

Código comentado:

<!-- Agrupa imagem com sua caption -->
<figure>
  <img src="gato.jpg" alt="Um gato preto">
  <!-- Legenda associada à imagem -->
  <figcaption>Figura 1: Gato tomando sol</figcaption>
</figure>

Vantagens:

  • Associa legenda com imagem semanticamente
  • Melhor para acessibilidade
  • Melhor para SEO
  • Mais legível o código

Vídeo com <video>

Criada em: HTML5 (2014)

Propósito: Insere vídeos nativamente sem necessidade de plugin.

Código comentado:

<!-- Video com controles -->
<video width="320" height="240" controls>
  <!-- Tipo de arquivo é especificado com <source> -->
  <source src="filme.mp4" type="video/mp4">
  <source src="filme.webm" type="video/webm">
  Seu navegador não suporta vídeo HTML5.
</video>

Atributos:

  • controls - Mostra barra de controle (play, pause, volume)
  • autoplay - Inicia o vídeo automaticamente (cuidado!)
  • loop - Reinicia quando termina
  • muted - Começa sem som
  • poster - Imagem antes de começar
  • width/height - Dimensões

Formato de vídeo recomendado:

Sempre ofereça múltiplas fontes para compatibilidade máxima:

  • MP4 (.mp4) - Mais compatível
  • WebM (.webm) - Melhor compressão
  • Ogg (.ogv) - Alternativa

Áudio com <audio>

Criada em: HTML5 (2014)

Propósito: Insere arquivos de áudio nativamente.

Código comentado:

<audio controls>
  <source src="musica.mp3" type="audio/mpeg">
  <source src="musica.ogg" type="audio/ogg">
  Seu navegador não suporta áudio HTML5.
</audio>

Atributos similares ao vídeo:

  • controls - Mostra controles de áudio
  • autoplay - Inicia automaticamente
  • loop - Repete
  • muted - Começa mudo

Formatos de áudio:

  • MP3 (.mp3) - Muito compatível
  • WAV (.wav) - Qualidade alta, arquivo grande
  • OGG (.ogg) - Formato aberto

Formatos de imagem

Formato Extensão Melhor para Características
JPEG .jpg Fotos Bom compressão, sem transparência
PNG .png Gráficos, transparência Lossless, com transparência
GIF .gif Animações simples Até 256 cores, pode animar
WebP .webp Web moderna Melhor compressão, mais novo
SVG .svg Ícones, logos Vetorial, escalável infinitamente

Boas práticas para imagens

  • Sempre use atributo alt
  • Otimize tamanho de arquivo (use ferramentas de compressão)
  • Use formato apropriado para cada tipo de imagem
  • Especifique width e height para melhorar performance
  • Use lazy loading em imagens fora da tela inicial
  • Forneça múltiplos formatos para compatibilidade
  • Use <figure> quando houver legenda
  • Considere usar WebP para melhor compressão
