👑 MAIOR PRIORIDADE

Regra de Ouro:

Quanto mais PRÓXIMO do elemento, maior a prioridade!

  • Inline = grudado no elemento → prioridade MÁXIMA
  • Interno = no mesmo arquivo → prioridade MÉDIA
  • Externo = arquivo separado → prioridade BAIXA

💡 Qual usar?

✅ CSS EXTERNO (RECOMENDADO para produção)

  • Reutilizável em múltiplas páginas
  • Navegador faz cache
  • Melhor organização

⚠️ CSS INTERNO (para páginas únicas)

  • Landing pages
  • Estilos específicos de uma página

❌ CSS INLINE (evitar quando possível)

  • Dificulta manutenção
  • Não é reutilizável
  • Usar apenas para ajustes pontuais ou estilos dinâmicos (JavaScript)
