O elemento <a> - Âncoras e Links

Criada em: HTML 1.0 (1991)

Propósito: A tag <a> (de "anchor", âncora) cria links que conectam páginas. É o elemento mais importante que torna a web uma rede.

Por que foi criada: Sem links, a web seria apenas um conjunto de documentos isolados. Tim Berners-Lee sabia que a capacidade de vincular documentos era fundamental.

Sintaxe básica do Link

<a href="url">Texto do link</a>

Exemplo com comentários:

<!-- href = hypertext reference (referência do hipertexto) -->
<a href="https://www.google.com">Ir para Google</a>

Exemplo vivo:

Visite Google para fazer uma busca.

Tipos de Links

1. Links Absolutos (URLs completas)

Link para um site externo com a URL completa:

<a href="https://www.wikipedia.org">Wikipedia</a>

Característica: Começa com protocolo (http://, https://)

2. Links Relativos (caminhos locais)

Link para outra página no mesmo site:

<!-- Link para arquivo no mesmo diretório -->
<a href="pagina.html">Próxima Página</a>

<!-- Link para arquivo em subdiretório -->
<a href="pasta/arquivo.html">Arquivo em pasta</a>

<!-- Link para arquivo no diretório pai -->
<a href="../index.html">Voltar para início</a>

3. Links de Email

<!-- mailto: abre o programa de email padrão -->
<a href="mailto:seu@email.com">Envie um email</a>

4. Links para Telefone

<!-- tel: permite ligar em dispositivos móveis -->
<a href="tel:+5511999999999">Ligar</a>

5. Links Âncoras (para outra parte da página)

<!-- Primeiro, defina um ID no elemento alvo -->
<h2 id="secao-contato">Contato</h2>

<!-- Depois, use # para referenciar o ID -->
<a href="#secao-contato">Ir para Contato</a>

6. Links entre páginas com âncora

<a href="pagina.html#secao-especifica">Ir para seção</a>

Atributos importantes da tag <a>

href

O que faz: Define o destino do link

Obrigatório: Sim

target

O que faz: Define como o link abre

<a href="pagina.html" target="_blank">Abrir em nova aba</a>

Valores:

  • "_blank" - Abre em nova aba/janela
  • "_self" - Abre na mesma aba (padrão)
  • "_parent" - Abre na janela pai (frameset)
  • "_top" - Abre no topo (frameset)

title

O que faz: Texto que aparece ao passar mouse (tooltip)

<a href="index.html" title="Voltar para página inicial">Início</a>

download

Criada em: HTML5 (2014)

O que faz: Força o download do arquivo em vez de abrir

<a href="documento.pdf" download>Baixar PDF</a>

rel

O que faz: Define o tipo de relação entre documentos

<a href="https://site-confiavel.com" rel="external">Site externo</a>

Valores comuns:

  • "external" - Link para site externo
  • "nofollow" - Não contar para SEO
  • "noopener" - Segurança em links external com target="_blank"

Boas práticas em links

1. Texto descritivo

❌ <a href="pagina.html">Clique aqui</a>

✅ <a href="sobre.html">Saiba mais sobre nós</a>

2. Links externos em nova aba

✅ <a href="externa.com" target="_blank" rel="noopener noreferrer">

3. Use URLs relativas para links internos

❌ <a href="https://meusite.com/produtos.html">
✅ <a href="produtos.html">

4. Forneça contexto

❌ <a href="documento.pdf">Documento</a>
✅ <a href="documento.pdf">Baixar relatório completo (PDF, 2MB)</a>

5. Use title para informações adicionais

✅ <a href="index.html" title="Voltar à página inicial">Início</a>

Navegação estruturada com <nav>

Criada em: HTML5 (2014)

Propósito: Elemento semântico que marca seções de navegação principais.

Exemplo:

<nav>
  <ul>
    <li><a href="index.html">Início</a></li>
    <li><a href="produtos.html">Produtos</a></li>
    <li><a href="contato.html">Contato</a></li>
  </ul>
</nav>

Vantagens:

  • Melhora acessibilidade (leitores de tela identificam navegação)
  • Melhora SEO
  • Código mais semântico
  • Facilita manutenção

Exemplo completo: Menu de navegação

<nav>
  <h2>Menu</h2>
  <ul>
    <li><a href="index.html">Início</a></li>
    <li><a href="sobre.html" title="Conheça a empresa">Sobre Nós</a></li>
    <li><a href="servicos.html">Serviços</a></li>
    <li><a href="contato.html">Contato</a></li>
    <li><a href="https://blog.com" target="_blank" rel="external">Blog</a></li>
  </ul>
</nav>
