Formulários HTML

Criados em: HTML 2.0 (1995)

Propósito: Coletam dados do usuário (texto, seleções, etc) e enviam para um servidor.

Por que foram criados: A Web precisava ser interativa. Formulários transformaram a web de um meio apenas leitura para um sistema bidirecional.

O elemento <form>

Propósito: Container que agrupa todos os elementos do formulário.

Sintaxe básica com comentários:

<!-- form é o container do formulário -->
<form action="processar.php" method="POST">
  <!-- Elementos do formulário vão aqui -->
</form>

Atributos:

action

O que faz: Especifica para onde enviar os dados do formulário

<form action="https://servidor.com/formulario">

method

O que faz: Define como enviar os dados

  • "GET" - Dados aparecem na URL (seguro para dados não sensíveis)
  • "POST" - Dados são enviados no corpo da requisição (mais seguro)

<form method="POST">

enctype

O que faz: Define formato de codificação

  • "application/x-www-form-urlencoded" (padrão)
  • "multipart/form-data" (necessário para upload de arquivos)

Elementos de entrada: <input>

Criada em: HTML 2.0 (1995)

Propósito: Campo para usuário inserir dados. É uma tag vazia.

Tipos principais de input:

type="text"

<!-- Campo de texto simples -->
<input type="text" name="nome" placeholder="Digite seu nome">

Atributos: placeholder (dica), maxlength (máx caracteres)

type="email"

<input type="email" name="email" required>

Criada em: HTML5 (2014)
Validação: Verifica automaticamente se é email válido

type="password"

<input type="password" name="senha">

Efeito: Mascara caracteres com •••••

type="number"

<input type="number" name="idade" min="0" max="120">

Criada em: HTML5 (2014)
Características: Só aceita números, pode especificar min/max

type="date"

<input type="date" name="data_nascimento">

Criada em: HTML5 (2014)
Efeito: Abre calendário para seleção

type="checkbox"

<input type="checkbox" name="aceitar" value="sim">

Efeito: Caixa que pode estar marcada ou não

type="radio"

<input type="radio" name="genero" value="masculino"> Masculino
<input type="radio" name="genero" value="feminino"> Feminino

Característica: Apenas uma opção por vez (mesmo name)

type="file"

<input type="file" name="documento">

Efeito: Permite usuário escolher arquivo

type="hidden"

<input type="hidden" name="id_sessao" value="abc123">

Característica: Não aparece na página, mas envia valor

type="submit"

<input type="submit" value="Enviar">

Efeito: Botão que envia o formulário

type="button"

<input type="button" value="Clique">

Efeito: Botão genérico (precisa de JavaScript para funcionar)

type="reset"

<input type="reset" value="Limpar">

Efeito: Limpa todos os campos volta aos valores padrão

Outras tags de formulário

<label>

Criada em: HTML 4.0 (1997)

Propósito: Associa texto descritivo com um campo de entrada

<label for="email">Email:</label>
<input type="email" id="email" name="email">

<textarea>

Criada em: HTML 2.0 (1995)

Propósito: Campo para texto longo (múltiplas linhas)

<textarea name="mensagem" rows="5" cols="40"></textarea>

<select> e <option>

Criadas em: HTML 2.0 (1995)

Propósito: Lista suspensa para escolher uma opção

<select name="pais">
  <option value="">Escolha um país</option>
  <option value="br">Brasil</option>
  <option value="arg">Argentina</option>
</select>

<fieldset> e <legend>

Criadas em: HTML 4.0 (1997)

Propósito: Agrupa campos relacionados com um título

<fieldset>
  <legend>Dados Pessoais</legend>
  <label>Nome: <input type="text"></label>
  <label>Email: <input type="email"></label>
</fieldset>

Atributos importantes do formulário

required

<input type="text" required>

Efeito: Campo obrigatório (não pode ser deixado em branco)

disabled

<input type="text" disabled>

Efeito: Desabilita o campo (não pode interagir)

value

<input type="text" value="Valor padrão">

Efeito: Valor inicial do campo

name

<input type="text" name="usuario">

Importância: Identifica o campo quando dados são enviados

id

<input type="text" id="email">

Importância: Permite associar com <label> e JavaScript

Exemplo completo: Formulário de cadastro

<form action="registrar.php" method="POST">
  <fieldset>
    <legend>Dados Pessoais</legend>
    
    <label for="nome">Nome Completo:</label>
    <input type="text" id="nome" name="nome" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
    
    <label for="idade">Idade:</label>
    <input type="number" id="idade" name="idade" min="18" max="120">
  </fieldset>
  
  <fieldset>
    <legend>Preferências</legend>
    
    <input type="checkbox" id="newsletter" name="newsletter" value="sim">
    <label for="newsletter">Receber newsletter</label>
  </fieldset>
  
  <input type="submit" value="Cadastrar">
  <input type="reset" value="Limpar">
</form>

Boas práticas em formulários

  • Sempre use <label> para campos
  • Marque campos obrigatórios com required
  • Use type apropriado (email, number, date, etc)
  • Agrupe campos relacionados com <fieldset>
  • Forneça placeholder para dicas
  • Especifique name de forma semântica
  • Use id para associar com labels
  • Valide no servidor (não apenas no navegador)
  • Mantenha formulários simples e concisos
