O que é HTML5?

HTML5 é a versão moderna de HTML, padronizada e lançada em 2014. Trouxe muitos recursos novos que tornaram a web mais poderosa e interativa.

Diferenças de versões anteriores:

  • Mais semântica: Elementos como <header>, <section>, <article>
  • Multimídia nativa: <video> e <audio> sem plugins
  • APIs JavaScript: Canvas, Geolocation, Storage, etc
  • Formulários avançados: Novos tipos de input com validação
  • Melhor doctype: Simples <!DOCTYPE html>
  • Atributos globais: data-*, contenteditable, draggable

Novos tipos de <input> do HTML5

type="email"

<input type="email" required>
Benefício: Validação automática de email

type="url"

<input type="url">
Benefício: Validação automática de URL

type="number"

<input type="number" min="0" max="100" step="5">
Benefício: Campo numérico com restrições

type="range"

<input type="range" min="0" max="100">
Efeito: Controle deslizante interativo

type="date"

<input type="date">
Efeito: Abre seletor de data

type="time"

<input type="time">
Efeito: Seletor de hora

type="color"

<input type="color">
Efeito: Seletor de cor

type="search"

<input type="search">
Uso: Campo de busca com validação

type="tel"

<input type="tel">
Benefício: Em móveis mostra teclado telefônico

Novos elementos de multimídia

<video>

Criada em: HTML5 (2014)

Permite reproduzir vídeos nativamente sem plugin Flash:

<video width="320" height="240" controls>
  <source src="filme.mp4" type="video/mp4">
  Navigador não suporta HTML5 video.
</video>

<audio>

Criada em: HTML5 (2014)

Reproduz áudio nativamente:

<audio controls>
  <source src="musica.mp3" type="audio/mpeg">
</audio>

<canvas>

Criada em: HTML5 (2014)

Área para desenhar gráficos com JavaScript:

<canvas id="myCanvas" width="200" height="100"></canvas>

Usado para: Gráficos, animações, jogos

<svg>

Criada em: 2011 (integrada ao HTML5)

Gráficos vetoriais escaláveis:

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="red"></circle>
</svg>

Novos elementos semânticos

<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>

(Cobertos na Lição 9)

<figure> e <figcaption>

Criadas em: HTML5 (2014)

Associam imagem com legenda:

<figure>
  <img src="imagem.jpg" alt="...">
  <figcaption>Descrição da imagem</figcaption>
</figure>

<mark>

Criada em: HTML5 (2014)

Destaca texto como importante

<p>Encontrei a palavra <mark>importante</mark></p>

Atributos globais HTML5

contenteditable

<p contenteditable="true">Clique para editar este texto</p>

Efeito: Usuário pode editar o conteúdo diretamente

data-*

<div data-id="123" data-categoria="produto"></div>

Propósito: Armazenar dados customizados acessíveis via JavaScript

draggable

<img draggable="true" src="imagem.jpg">

Efeito: Elemento pode ser arrastado

hidden

<p hidden>Este conteúdo está oculto</p>

Efeito: Esconde o elemento (similar a display: none em CSS)

spellcheck

<textarea spellcheck="true"></textarea>

Efeito: Ativa verificação de ortografia

translate

<p translate="no">Não traduzir este texto</p>

Efeito: Indica se o navegador deve traduzir

<meta> tags HTML5

charset

<meta charset="UTF-8">
Essencial: Define o conjunto de caracteres

viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Importância: Torna site responsivo em móveis

description

<meta name="description" content="Descrição para SEO">
Importância: Texto que aparece em buscas

keywords

<meta name="keywords" content="html, tutorial, web">
Nota: Menos importante para SEO moderno

author

<meta name="author" content="João Silva">
Uso: Identificar autor da página

theme-color

<meta name="theme-color" content="#3498db">
Efeito: Cor da barra de endereço em móveis

APIs HTML5 (JavaScript)

Geolocalização

navigator.geolocation.getCurrentPosition(function(position) {
  console.log(position.coords.latitude);
});

LocalStorage

localStorage.setItem('chave', 'valor');
var valor = localStorage.getItem('chave');

Propósito: Armazenar dados no navegador persistentemente

Canvas

var canvas = document.getElementById('myCanvas');
var ctx = canvas.getContext('2d');
ctx.fillRect(0, 0, 100, 100);

Propósito: Desenhar gráficos e animações

Web Workers

var worker = new Worker('worker.js');
worker.postMessage('dados');

Propósito: Executar scripts em background

Compatibilidade HTML5

Boas notícias: HTML5 é amplamente suportado em todos os navegadores modernos.

Verificação: Visite caniuse.com para verificar suporte

Para navegadores antigos:

  • Use fallback adequado (ex: <video> com múltiplas fontes)
  • Use polyfills para funcionalidades que faltam
  • Teste em navegadores antigos
  • Forneça alternativas acessíveis

Checklist HTML5

  • ☑ Usar <!DOCTYPE html>
  • ☑ <meta charset="UTF-8">
  • ☑ <meta viewport> para responsividade
  • ☑ <meta description> para SEO
  • ☑ Usar elementos semânticos (header, nav, main, footer)
  • ☑ Usar <h1> a <h6> corretamente
  • ☑ Atributos alt em imagens
  • ☑ Validar em validator.w3.org
  • ☑ Testar em múltiplos navegadores e dispositivos
  • ☑ Seguir boas práticas de acessibilidade
