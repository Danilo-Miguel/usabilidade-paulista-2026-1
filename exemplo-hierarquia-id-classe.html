CSS: Hierarquia, IDs e Classes

Exemplo focado em seletores e especificidade

1. Seletor de CLASSE (.classe)

Classes são REUTILIZÁVEIS. Pode usar a mesma classe em vários elementos.

No HTML: class="destaque"

No CSS: .destaque { ... }

Este parágrafo tem a classe "destaque" (fundo amarelo)

Este parágrafo tem a classe "alerta" (fundo vermelho)

Este parágrafo tem a classe "sucesso" (fundo verde)

Posso usar "destaque" de novo! Classes são REUTILIZÁVEIS. ✅

2. Seletor de ID (#id)

IDs são ÚNICOS. Cada ID só pode aparecer UMA VEZ na página.

No HTML: id="meu-id"

No CSS: #meu-id { ... }

Este parágrafo tem o ID "texto-especial" (texto vermelho). Não posso usar este ID em outro elemento! ⚠️

Quando usar ID?

  • Elementos únicos de layout (header, footer, nav principal)
  • Âncoras de navegação (links internos)
  • JavaScript (getElementById é muito rápido)

Quando usar CLASSE?

  • Estilos que se repetem (botões, cards, badges)
  • Na dúvida, USE CLASSE! 👍

3. Combinando Múltiplas Classes

Um elemento pode ter VÁRIAS classes ao mesmo tempo!

No HTML: class="classe1 classe2 classe3"

Este parágrafo tem duas classes: "destaque" E "texto-grande"

Este tem TRÊS classes: "alerta", "texto-grande" e "centralizado"

Isso permite criar estilos modulares e reutilizáveis! 🎯

4. Hierarquia CSS - Quem Vence?

Quando há conflito, o seletor MAIS ESPECÍFICO vence!

Este parágrafo tem classe "texto-azul" (azul). A classe (especificidade 10) vence o seletor de tag p (especificidade 1).

Este tem classe "texto-azul" E ID "texto-especial" (vermelho). O ID (especificidade 100) vence a classe (especificidade 10)!

Este parágrafo está dentro do ID "conteudo" e tem classe "destaque". O seletor #conteudo p.destaque tem especificidade 111 e deixa em itálico!

Seletor Especificidade Exemplo
Inline Style 1000 style="color: red;"
ID 100 #meu-id
Classe 10 .minha-classe
Tag (elemento) 1 p

5. Boas Práticas

✅ FAÇA:

  • Use classes para estilos reutilizáveis (botões, cards, badges)
  • Use IDs para elementos únicos de layout
  • Combine classes para criar estilos modulares
  • Mantenha especificidade baixa (mais fácil de sobrescrever)
  • Use nomes descritivos: .botao-primario melhor que .azul

❌ EVITE:

  • Usar ID para estilos que se repetem
  • Especificidade excessiva: body div#x section.y p.z
  • IDs múltiplos na mesma página (HTML inválido!)
  • Inline styles (dificulta manutenção)
  • Nomes genéricos: .texto, .caixa
