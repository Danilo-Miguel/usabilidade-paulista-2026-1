O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). É uma linguagem usada para criar páginas web, estruturando o conteúdo através de tags e elementos.

História do HTML

O HTML foi criado em 1989 por Tim Berners-Lee, um físico britânico que trabalhava no CERN (Organização Europeia para a Pesquisa Nuclear). Berners-Lee precisava de uma forma de compartilhar documentos através de uma rede de computadores.

Evolução das versões:

  • HTML 1.0 (1991) - Versão inicial com tags básicas
  • HTML 2.0 (1995) - Primeira especificação oficial
  • HTML 3.2 (1997) - Adição de tabelas e applets
  • HTML 4.01 (1999) - Separação de conteúdo e apresentação
  • XHTML 1.0 (2000) - Versão XML do HTML
  • HTML5 (2014) - Versão moderna com muitos recursos novos

Por que o HTML foi criado?

Antes do HTML, compartilhar documentos em rede era complicado. Cada programa usava seu próprio formato proprietário. Tim Berners-Lee criou HTML para resolver esse problema:

  • Simplicidade - Tags fáceis de aprender e usar
  • Portabilidade - Funciona em qualquer computador
  • Flexibilidade - Suporta texto, imagens e links
  • Skalabilidade - Cresce conforme as necessidades

Como o HTML funciona?

O HTML usa um sistema de tags para marcar diferentes partes do conteúdo. Uma tag é uma instrução escrita entre colchetes angulares (< >) que diz ao navegador como interpretar o conteúdo.

Exemplo básico de uma tag:

<p>Este é um parágrafo</p>

A tag <p> abre o parágrafo e </p> fecha o parágrafo.

Navegador: o interpretador do HTML

Quando você acessa uma página web, o navegador (Chrome, Firefox, Safari, Edge) faz o seguinte:

  1. Baixa o arquivo HTML do servidor
  2. Lê e interpreta todas as tags
  3. Exibe o conteúdo de forma formatada na tela
  4. Executa qualquer JavaScript associado
  5. Aplica estilos CSS se houver

O que não é HTML?

  • Não é uma linguagem de programação - HTML não tem lógica de programação
  • Não é CSS - CSS é para estilo visual
  • Não é JavaScript - JavaScript é para interatividade
  • HTML é apenas marcação - Descreve a estrutura do conteúdo

Conceitos-chave do HTML

1. Tags e Elementos

Uma tag é o código (<p>), e um elemento é a tag mais o conteúdo (<p>Olá</p>).

2. Atributos

Atributos fornecem informações adicionais sobre elementos. Exemplo: <a href="https://google.com">Google</a>

3. Estrutura Aninhada

Elementos HTML podem conter outros elementos:

<div>
  <p>Parágrafo dentro de div</p>
</div>

4. Semântica

HTML moderno enfatiza o significado: usar <header> para cabeçalho é melhor que <div>, pois comunica intenção.
